# Doric Skills — Next.js Starter

## Requirements
- Node.js 18.18+ (20+ recommended)
- VS Code recommended

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Main pages
- /
- /about
- /skills
- /courses
- /gallery
- /contact
